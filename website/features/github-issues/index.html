One-click GitHub issues

Uses your own account

Configure the destination once. After that, a finished recording becomes a GitHub issue with one action: summary, protected report link and all.

Needs
A fine-grained GitHub token per repository and protected publishing
Optional
An AI model to write the summary
Help
Connect a repository

What happens when you file

  1. Stop the recording

    The report opens with File issue in the header and the editable draft above the evidence.

  2. Choose File GitHub issue

    The extension checks the repository, prepares the summary if a model is configured, publishes the report to your Cloudflare project, and creates the issue with a link to it.

  3. Open the issue

    When it finishes, the issue opens. Later, the report shows View issue instead.

A full-page progress view shows the current stage and has Cancel. Cancelling stops further work and keeps saved drafts and deployments. It cannot undo an upload or issue request that GitHub or Cloudflare already accepted.

Several repositories

Add as many repositories as you file into, each with its own token scoped to that repository with Issues: Read and write. Saving checks access to each one. The arrow beside File issue picks the destination; new reports remember your last choice, and an existing draft keeps the repository it was started for.

Avoiding duplicates

If the network fails after GitHub may have received the request, the extension does not post again automatically. Check GitHub issue looks for the earlier request first, and a retry reuses the existing deployment instead of uploading again.

Who can see what

  • The issue title and summary are as visible as the repository. In a public repository, anyone can read them.
  • The linked report requires Cloudflare Access sign-in, independent of GitHub permissions.
  • Tokens stay in extension storage and are never included in exports or published reports. Unpublishing a report does not delete the issue.

Prefer another tracker? Use Publish report only for a protected link, or export a ZIP and attach it anywhere.
