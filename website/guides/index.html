Guides

How to write bug reports a developer or a coding agent can act on, and how to hand Session Recorder exports to the tools you use.

Coding agents

  • With CursorAttach report.md to Cursor’s Agent.
  • With CodexGive Codex the browser evidence it cannot collect itself.
  • With ChatGPTUpload one report instead of screenshots and log fragments.
