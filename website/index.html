Record the bug. Point at it. File the issue.

Session Recorder is a free, open-source Chrome extension for QA and product teams. Reproduce a bug, annotate exactly what is wrong, and file a GitHub issue that arrives written, with the full recording behind a login.

Add to ChromeSee all features

No account or subscription with us. Recording and ZIP export work entirely in your browser. AI summaries and publishing use your own model provider and Cloudflare account, where their charges apply.

One path from bug to issue

Configure your integrations once. After that, filing is a single action on a finished recording.

  1. Record

    Reproduce the bug in Chrome. Clicks, typing, console errors, network requests and screenshots go onto one timeline, including tabs the app opens.

    Browser recording

  2. Annotate

    Turn on Annotate, click an element or drag a rectangle, and say what is wrong. Numbered pins lead the report.

    Live annotations

  3. File

    Choose File GitHub issue. Your model writes the summary, the report publishes behind Cloudflare Access, and the issue opens with a link.

    GitHub issues

Useful on its own. Better connected.

Nothing here requires an integration. Each one you add removes a manual step.

Works without any account

Stays in your browser until you export it.

  • Interactions, console and network capture
  • Live annotations and screenshot markup
  • Screenshots and tab video
  • Local storage and capture-time redaction
  • ZIP export for people and coding agents

With your own accounts

Configured once; data goes directly to the service you choose.

  • AI issue summaries and session names
  • One-click GitHub issues, several repositories
  • Reports on your Cloudflare Pages, behind Access
  • Voice note transcription

Evidence you can share with care

Authorization headers, cookies, token-like fields, sensitive URL parameters and password inputs are masked before anything is stored. Redaction is pattern-based and does not read screenshots, video or audio, so review a report before it leaves your team. Published reports require sign-in through your Cloudflare Access policy, and API keys are never written into exports or reports. How privacy and redaction work.

Compared with hosted bug tools

Jam, Marker.io, BugHerd, Userback and BrowserStack Bug Capture offer shared workspaces, client feedback, broad integrations and team administration. Session Recorder is narrower: free, open source, GitHub-first, and run on accounts you already control. Read the comparisons, including when each tool is the better choice.

Hand bugs to coding agents

Exports are Markdown with a shared clock across every event, sized to fit a context window. The guides show how to use them.
