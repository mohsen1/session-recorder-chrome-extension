One-click GitHub issues

Connect a repository once, then file an issue directly from a finished recording.

Connect your repository

  1. Complete protected publishing setup. Optionally configure AI summaries to draft the issue automatically.
  2. Open Settings → GitHub, choose Add repository, and enter owner/repository.
  3. Choose Create a GitHub token. Select the correct resource owner and only the repository you want to file into. Give it Issues: Read and write; GitHub includes required Metadata access. Choose an expiration and generate the token.
  4. Paste the token into that repository’s token field and choose Save GitHub settings. The extension checks repository access before saving.

Add another repository for each destination you use. Each repository has its own token, so credentials can be scoped to just that repository.

See GitHub’s issue creation permissions for the API requirements.

File from the report

Stop recording to open the report. Choose File GitHub issue. The extension generates a summary when configured, publishes the protected report, and creates the issue with a link. An existing or edited draft is preserved.

The arrow beside File issue selects a configured repository. New reports remember your last selection; existing drafts keep their saved destination.

A full-page progress screen shows repository verification, summary preparation, publishing and issue creation. Cancel stops further work and keeps saved drafts and published reports. If GitHub may already have received the issue, use Check GitHub issue to find it before retrying. Cancellation does not undo a completed upload or issue creation.

Keep the report tab open while filing. Once complete, View issue opens the created issue. The summary is visible to everyone who can read the repository; the linked report still requires Access sign-in.

If filing fails

  • 401 or 403: check the token’s expiration, repository selection and Issues permission. An organization may require token approval.
  • 404: check the repository spelling and whether the token can access it.
  • Uncertain response: use Check GitHub issue to reconcile the request before retrying. The extension checks for an accepted request to avoid duplicate issues.
  • Publishing error: follow the Cloudflare troubleshooting steps.

The token stays in local extension storage and is excluded from reports and exports. Unpublishing a report does not delete its GitHub issue.
